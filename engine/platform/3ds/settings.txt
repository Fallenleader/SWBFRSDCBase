# Aurek (Nintendo 3DS) settings: sdmc:/3ds/Aurek/settings.txt, next to aurek.3dsx
# One KEY=VALUE per line; '#' starts a comment.  Every value below is the default, so deleting a line changes nothing.
#
# Game files: game.iso or GAME/PSP_GAME/... in sdmc:/3ds/Aurek, or (if not there) in sdmc:/3ds/SWBFRS, where the earlier 3DS port
# keeps them - along with its converted audio (converted/...adp, DSP-ADPCM, written by the 3DS conversion tool or the earlier
# port's first start).  Nothing needs copying if the earlier port already runs.  Sound needs sdmc:/3ds/dspfirm.cdc (run DSP1 once).
# Videos: none are played (stubbed on this build).
#
# Controls (the PSP game's layout and its one-stick scheme; 3DS button = PSP button):
#   B = CROSS, A = CIRCLE, Y = SQUARE, X = TRIANGLE, L / ZL = L, R / ZR = R, Circle Pad = the analogue stick, d-pad, START, SELECT.
#   L + R + START + SELECT: quit (the HOME menu works too).  The C-stick is not used, so a New 3DS plays the same way.
#   SELECT tapped: next level (a new match).  SELECT + L: the level before.  SELECT + R: figures / debug text on / off (bottom screen).
#   SELECT + SQUARE: play (a soldier in a conquest match with bots) / free camera.  SELECT + CIRCLE: the model gallery.
#   On foot: stick up / down runs forward / back, stick left / right turns the soldier and the view (as the PSP game: the turn
#            builds up over 1.5 s; AK_SINGLE_STICK_TURN=0 instead turns the soldier toward the stick and runs that way, the view
#            swinging in behind).  CROSS fire, SQUARE secondary (the thermal detonator), R hold lock-on (then the stick
#            moves around the target), L tap jump, L hold sprint, d-pad UP get in / out of a vehicle or man a turret (the stick
#            aims it), CIRCLE roll, TRIANGLE zoom.
#   Ground vehicles: stick throttle / steer, CROSS fire, SQUARE secondary, L hold boost, UP get out.
#   Flyers: stick pitch (forward = nose down; AK_INVERT_Y_VEHICLE / AK_INVERT_Y_SPACE flip it) and turn / bank; on the ground R takes off; flying, R speeds up
#            toward the cruising speed and L slows toward the stall speed; in space, tap R then hold it again within 0.5 s to boost.
#   Heroes: when your side's hero is offered, d-pad UP takes it, DOWN declines.
#   Stereo 3D: raise the 3D slider.  The HUD sits on the screen; the world goes behind it.
# button layout: psp (the game's, above) or legacy (R fire, L lock, CROSS jump, TRIANGLE get in)
AK_BUTTONS=psp
# the one stick: 1 = turns (the PSP game), 0 = the soldier faces where it points and runs
AK_SINGLE_STICK_TURN=1
# debug text colour, 0xRRGGBB (drawn on the bottom screen's black)
AK_DEBUG_TEXT_RGB=0xFFFFFF

AK_GALLERY=0

# ---- stereo 3D (the 3D slider; 0 = always 2D, which also saves the second eye's drawing)
AK_3D=1
# separation at the top of the slider, percent of the screen width
AK_3D_STRENGTH=3
# the distance (metres) that sits on the screen: nearer things come out of it, farther ones go behind
AK_3D_DEPTH=4.0
# clipping distances in metres (space levels have ships and planets several km away)
AK_NEAR=0.75
AK_FAR=8000
# vertex colour scale: the game's baked vertex colours use 128 = full brightness, so 2 is the game's look
AK_COLOUR_SCALE=2.0
# distance fog in metres (end <= start: none)
# the PSP game's own picture (1): its fog distances, no command post glow, models lit only by the level's light samples
#   (AK_FOG / AK_POST_GLOW still override); 0 = Aurek's defaults
AK_CLASSIC=0
# object lighting from the level's light samples (the game's, GISN): 1 on, 0 flat
AK_LIGHT=1
# the level's own fog, percent (as the PSP port's RS_FOG): 100 the game's distances, 25 farther; AK_FOG_START / AK_FOG_END override
AK_FOG=25
AK_FOG_START=0
AK_FOG_END=0
# back-face culling of solid level surfaces: 0 = off (as the game draws: some surfaces are single-sided panels meant to be seen
# from both sides), 1 = on (faster on the 3DS's GPU; holes appear where such panels are seen from behind), 2 = cull the other
# side.  See-through surfaces and models are always drawn from both sides.
AK_CULL=0
# textures: 0 = 16-bit formats picked per texture without losing its alpha (half the memory), 1 = 32-bit
AK_TEX_32BIT=0
# depth pull of decals and overlays toward the camera, in 1/10,000,000 of the depth range
AK_3DS_DEPTH_BIAS=100

# ---- memory (the Old 3DS gives an application 64 MB in all)
# main memory for one level's data, in MB (a match on Hoth or Space Hoth uses about 23)
AK_LEVEL_MB=26
# converted speech kept in memory, in MB
AK_SPEECH_CACHE_MB=2
# the GPU's command buffer and the per-frame vertex memory (two of them), in KB
AK_3DS_CMDBUF_KB=1024
AK_3DS_VTX_KB=1024
